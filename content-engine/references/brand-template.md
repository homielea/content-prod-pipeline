# Brand file template

Every brand lives at `references/brands/<brand>.md` (repo/project root). This
is the contract the content-engine and landing-pass skills read from — a brand
file must fill every section below. Copy this template to start a new brand.

Rules of the system:

- The brand file is the ONLY place channel-specific voice, format, thesis, or
  sign-off may live. Skills stay channel-agnostic.
- "LOCKED" means locked: skills follow the format section exactly and never
  restructure it, even when a generic best practice disagrees.
- The live-examples table is the compounding asset — log what actually shipped
  and how it performed.

---

```markdown
# <Brand Name> — brand file

## Identity
One short paragraph: what this channel is, who it's for, and the promise a
viewer can rely on.

## Voice
Adjectives + a sentence on how it sounds out loud. Include 1–2 verbatim example
lines that ARE the voice, and 1–2 lines that are NOT (near-misses that sound
almost right).

## Running thesis (optional)
The through-line argument of the channel, stated in one or two sentences, plus
the weaving rule (e.g., "only where true to the material — never forced").
Omit the section if the brand has no running thesis.

## Locked format
The exact structure of a piece, with timings. State the prose rules (e.g.,
full prose vs. bullets) and the EXACT sign-off line in quotes, character for
character.

## Cutdown rules
What changes (and what must never change) when cutting Shorts/TikTok/Reels
versions: length cap, hook sharpening, whether the sign-off stays.

## Topics & boundaries
What the channel does and does not talk about. Recurring motifs worth reusing.

## Live examples (grow this over time)
| Hook / Title (as shipped) | Type | Why it earned the watch | Performance |
|---|---|---|---|
| | | | |
```
